About this page

This page lists the security measures in place and the companies that help us run Nusuh Books. See the Security and controls page for how the software protects each company’s books.

1. Security measures

MeasureWhat we do
Encryption in transitAll traffic uses HTTPS (TLS)
Access controlRole-based permissions; the Administrator controls who can see and do what
Audit trailAdministrator and key accounting actions are logged and cannot be edited by users
PasswordsStored only as salted hashes
Vulnerability reportsReport to {{contact.email}}

We do not currently hold an independent security certification.
